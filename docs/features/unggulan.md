# Fitur Unggulan Zurui

Zurui dirancang untuk memberikan pengalaman terbaik baik bagi administrator maupun pembaca. Berikut adalah fitur-fitur utama yang membuat Zurui menonjol dari CMS manga lainnya.

## 🚀 Fitur Utama (Highlight)

### 🤖 Mesin Scraper Otomatis (Komiku)
Impor ribuan manga dengan sekali klik. Mesin scraper kami berjalan di latar belakang, membiarkan Anda tetap fokus mengelola situs tanpa harus menunggu proses selesai.
- **Background Processing:** Berjalan di server secara aman tanpa membebani browser.
- **Anti-Duplikat:** Sistem cerdas yang mencegah bab yang sama diimpor dua kali.
- **Monitoring Langsung:** Pantau progress scraping secara real-time dari dashboard.

### 🏠 Installer Web Satu Klik (Tanpa Terminal)
Instalasi CMS semudah menginstal aplikasi di HP. Anda tidak perlu menyentuh terminal atau perintah SSH yang rumit.
- **Wizard 7 Langkah:** Mulai dari lisensi hingga pengaturan admin.
- **Cek Persyaratan:** Otomatis mendeteksi jika server Anda siap.
- **Self-Destruct:** File instalasi otomatis dihapus setelah selesai demi keamanan maksimal.

### 📖 Pembaca Premium (Mobile First)
Pengalaman membaca yang mulus di perangkat apa pun dengan kontrol yang intuitif.
- **Mode Beragam:** Long-strip (scrolling), Single Page, dan Double Page.
- **Keyboard Shortcuts:** Navigasi cepat dengan tombol panah dan spasi.
- **Fit-to-Width:** Gambar otomatis menyesuaikan lebar layar secara sempurna.

## 💎 Ekosistem Pengguna & Admin

::: info EKOSISTEM PENGGUNA
Memberikan alasan bagi pembaca untuk terus kembali ke situs Anda.
- **Sistem Bookmark:** Simpan manga favorit ke perpustakaan pribadi.
- **Riwayat Baca:** Lanjutkan membaca tepat di mana mereka berhenti sebelumnya.
- **Komentar Berulir:** Diskusi aktif dengan sistem reply seperti media sosial.
- **Login Sosial:** Masuk cepat menggunakan Google OAuth.
:::

::: tip PANEL ADMIN LENGKAP
Kelola konten Anda dengan efisiensi maksimal.
- **Dashboard Statistik:** Lihat pertumbuhan manga, bab, dan pengguna.
- **Pembersih Sampah:** Hapus bab duplikat dan file yang tidak terpakai secara otomatis.
- **Manajemen Laporan:** Tangani laporan error atau konten dari pengguna dengan mudah.
:::

## 🎨 Desain & Performa Modern

### ✨ Estetika Premium
Zurui dibangun dengan tren desain terbaru menggunakan **Glassmorphism** dan **Tailwind CSS v4**.
- **Dark & Light Mode:** Transisi halus antara mode gelap dan terang.
- **Mikro-Animasi:** Interaksi yang terasa hidup dan responsif.
- **Mobile First:** Akses lancar dari smartphone tanpa terasa seperti web "lama".

### 🔍 Optimasi SEO (Search Engine Ready)
Memastikan manga Anda berada di peringkat teratas hasil pencarian Google.
- **Server Side Rendering (SSR):** Konten dapat dirayapi langsung oleh bot pencari.
- **Dynamic Meta Tags:** Judul dan deskripsi otomatis mengikuti konten manga.
- **Semantic HTML:** Struktur kode yang bersih dan sesuai standar SEO modern.
